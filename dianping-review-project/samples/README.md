# 样本约定

仓库不包含真实大众点评评论截图，也不包含虚构的真实用户评价。

运行 `python -m scripts.make_demo --directory data/demo` 生成明确标记的合成截图和模拟 OCR 输入，用于测试数据流程。模拟输入不是 OCR 实际识别结果。

真实样本仅存本地 `data/screenshots/` 或 `samples/private/`（均被 Git 忽略）。在上传给协作者或云端前遮挡昵称、头像和个人主页入口；不遮挡日期、星星、正文及连续屏幕重叠。附上截图顺序、屏幕尺寸/缩放、是否手动展开及 manifest。不要把验证码、登录凭证或其他微信聊天保存到样本中。
